Accuracy and safe use

Microsoft 365 behavior changes over time and can vary with licenses, tenant configuration, permissions, and product updates. Check current Microsoft documentation and test scripts in a non-production environment before using them against important workloads.

Review commands before execution, use least-privilege permissions, and never publish passwords, private keys, certificates, access tokens, real tenant identifiers, internal URLs, or unredacted logs in public discussions.

Found an issue or have a correction? Open an issue in the M365Buddy GitHub repository. Please include a sanitized description and the affected page URL.
