Why I built M365Buddy

Microsoft 365 administration often involves connecting several pieces: permissions, policies, automation, reports, and troubleshooting. M365Buddy is my place to document that work in a way people can revisit—whether they need a quick explanation, a repeatable PowerShell approach, or a deeper walkthrough.

The website and YouTube channel are complementary: articles provide searchable steps and code references, while videos can show the workflow in action.

How I approach technical content

I aim to explain the prerequisites, permissions, commands, expected output, and limitations—not just provide a snippet of code. Microsoft 365 features can change and may behave differently across tenants, licenses, and configurations, so readers should verify current documentation and test safely before using scripts in production.

Security first: never post tenant secrets, private keys, PFX files, access tokens, real tenant identifiers, internal URLs, or unredacted logs in public comments.
